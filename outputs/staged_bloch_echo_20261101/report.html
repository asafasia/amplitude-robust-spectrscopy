Staged gradient optimization: two-level prototype

Start with 10–20 MHz, focus on 20–30 MHz, consolidate 10–30 MHz, then repeat through 50–60 MHz. A single waveform is carried forward. Each stage adjusts duration, cutoff, continuous polynomial exponent, and reversal time. Nearby integer orders are checked with the remaining parameters reoptimized.

SLSQP uses finite-difference gradients with log-scaled cutoff/reversal variables. All stages guard the original linewidth and contrast on 5–60 MHz, including the 5–10 MHz protection band. C₅₀ must exceed 0.4. Earlier bands return to the cumulative objective; their best intermediate values are not frozen. This permits trade-offs above the original baseline.

This is a two-level model, with DRAG beta=0, T₁=51.24 µs and T₂=7.31 µs. The original reference is recomputed in this same model. No multilevel leakage or hardware validation is claimed. The original three-level result is not substituted for this baseline.

Preferred candidate: integer_p1

50 MHz FWHM: 145.783 kHz (original 152.453 kHz). Contrast: 0.40237 (original 0.37889). This is 3.35 times the conventional T₂ linewidth reference, 43.54 kHz. That reference is not a proven bound for this finite-duration echo.

Dense 551-point audit passed: True. Smallest linewidth gain: 4.253 kHz. Smallest contrast gain: 0.000959, at 5 MHz. Audit metrics.

The low-power contrast constraint and the lower order boundary p=1 are tight in this run. Simple parameter retuning gives a modest improvement. This does not establish a global optimum or a limit for more flexible pulse/phase families.

.venv/bin/python scripts/staged_echo_descent.py --output outputs/my_high_contrast_run --band-contrast-floor 0.4

Bounds: length 8–70 µs, cutoff 10⁻⁵–0.02, exponent 1–16, reversal 2–500 ns. Polynomial exponent is relaxed to a real number for descent; integer orders receive separate refinements. The fixed pulse is normalized to its actual complex-drive peak at each parameter evaluation. A nominal 50 MHz pulse is scaled from 5 to 60 MHz for the robustness ensemble.
